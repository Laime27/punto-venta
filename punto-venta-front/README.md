# Template React Liar

🚀 **Creador de proyectos React con Vite**  
Una plantilla base lista para arrancar proyectos React modernos, con herramientas y componentes ya configurados.

---

## Características incluidas

- **React Router DOM** para enrutamiento
- **shadcn-ui** con dashboard listo (modo claro y oscuro)
- **Login page** preconstruida
- **Sonner** para notificaciones tipo toast
- **React Hook Form** + **Zod** para validaciones de formularios
- **Tailwind CSS** + **Tailwind Merge**
- Estructura de carpetas organizada y lista para escalar

## Instalación

Para crear un nuevo proyecto basado en la plantilla:

```bash
pnpm dlx liar-template-react mi-nuevo-proyecto
```

## Desarrollo

```bash
cd mi-nuevo-proyecto
pnpm dev
```

## Scripts disponibles

| Comando | Descripción |
|---------|-------------|
| `pnpm dev` | Inicia el servidor de desarrollo |
| `pnpm build` | Genera el build de producción |
| `pnpm preview` | Previsualiza el build |
| `pnpm lint` | Ejecuta ESLint |
| `pnpm format` | Formatea el código con Prettier |
| `pnpm typecheck` | Verifica los tipos de TypeScript |
